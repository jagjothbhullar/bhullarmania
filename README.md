# BhullarMania · CDMX 2026

Bhullar bachelor weekend microsite — Mexico City, May 21–25, 2026.

Static site (HTML / CSS / vanilla JS), no build step.

## Sections
- **Hero** — countdown to wheels-up
- **Travel & HQ** — flights + Airbnb (2 houses · 11 BR · 13 beds · 6.5 baths) with photo gallery
- **Roster** — 17 guests with shirt sizes and clickable luchador cards
- **Merch** — coming-soon tease
- **The Card** — tabbed itinerary across 4 days
- **Field Guide** — neighborhood recs (coffee, cocktails, bites, sights, beyond Condesa)
- **FAQ** — packing, beds, cash, altitude, etc.

## Local dev

```bash
open index.html
```

## Deploy

Static site on Render — `render.yaml` included for one-click blueprint setup.
